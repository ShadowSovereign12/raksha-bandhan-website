# 🤝 Bro × Bro — Raksha Bandhan

> **Not just classmates — co-engineers of our dreams.**

A creative interactive Raksha Bandhan tribute website celebrating friendship, brotherhood, engineering life, and the bond between two childhood friends who ended up choosing different engineering paths — **Civil × CSE**.

The project combines my own ideas and creativity with **AI assistance** during the design and development process.

---

## 🌅 About the Project

This website is a digital Raksha Bandhan tribute created for my brother and childhood friend.

We followed different engineering paths:

- 🏗️ **Civil Engineering** — Structures, drawings, materials & foundations
- 💻 **Computer Science Engineering** — Code, systems, APIs & AI

Different colleges.  
Different branches.  
Same friendship. ❤️

The website turns that story into an interactive visual experience.

## 🎨 Design

The visual style combines:

- 🌅 Sunset photography
- 🟠 Warm orange accents
- 🌑 Dark engineering-inspired UI
- 🧵 Rakhi / thread symbolism
- 🏗️ Civil engineering blueprint elements
- 💻 CSE / coding references
